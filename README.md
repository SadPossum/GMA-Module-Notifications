# GMA Notifications Module

This repository owns the optional GMA Notifications module: durable notification history, read state, broadcasts, notification admin APIs, and module-owned notification persistence.

It is consumed by source-first applications and by the `gma-skeleton` composition repository as a Git submodule under `gma/modules/notifications`.

Useful entry points:

- `Gma.Modules.Notifications.slnx`
- `docs/README.md`
