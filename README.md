# GMA Notifications Module

This repository owns the optional GMA Notifications module: a durable tag catalog, user preferences, adapter routing and delivery attempts, inbox history/read state, broadcasts, admin APIs, and module-owned persistence.

It is consumed by source-first applications and by the `GMA-Skeleton` composition repository as a Git submodule under `gma/modules/notifications`.

Useful entry points:

- `Gma.Modules.Notifications.slnx`
- `docs/README.md`
